📄 Project Description:
This project involves the design and implementation of a basic 4-bit Arithmetic Logic Unit (ALU) using Verilog HDL. The ALU supports eight operations: Addition, Subtraction, Bitwise AND, Bitwise OR, Bitwise NOT, XOR, Increment, and Decrement. The design was synthesized and functionally verified using Xilinx Vivado, and a schematic was generated to visualize internal logic. Key performance metrics such as area utilization, power consumption, and critical path delay were also analyzed using Vivado's synthesis and implementation tools.
